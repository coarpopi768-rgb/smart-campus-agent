\# 智慧校园智能助手



\## 项目简介



基于大语言模型与 LangChain Agent 框架开发的智慧校园智能助手，实现校园信息查询、数据库问答、邮件通知等功能。



\## 技术栈



\* Python

\* LangChain

\* MySQL

\* Gradio

\* ZhipuAI GLM

\* SMTP



\## 核心功能



\### 校园信息查询



\* 学生信息查询

\* 课程信息查询

\* 教师信息查询



\### 数据库问答



\* 自然语言转 SQL

\* MySQL 数据查询



\### 邮件通知



\* 自动生成邮件内容

\* SMTP 邮件发送



\### 智能对话



\* 多轮会话

\* Agent 工具调用
